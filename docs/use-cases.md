## Potential Scenarios

Based on the capabilities of the Perth Extended Zone, potential use cases include:

### Data Residency & Sovereignty
Organizations in Western Australia requiring data to remain within the state for regulatory or compliance reasons can deploy workloads directly to the Extended Zone.

### Low-Latency Edge Workloads
Applications requiring minimal latency for end users in the Perth metropolitan area, such as:
- Media editing and content creation platforms
- Real-time collaboration tools
- Interactive applications

### Hybrid Cloud Extension
Enterprises with existing on-premises infrastructure in Perth can extend their environment to Azure using ExpressRoute at NextDC P1, creating a seamless hybrid cloud experience.

### Disaster Recovery from Eastern Australia
Organizations with primary workloads in Australia East or Southeast can use the Perth Extended Zone as a geographically diverse DR target (using ASR: Extended Zone → Parent region pattern).
